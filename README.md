# Local Dictionary

本地查词 IntelliJ Platform 插件。

- 依赖：无其他 IDE 插件
- 网络：完全禁止
- 触发：默认为鼠标停留 250ms
- 范围：编辑器英文标识符
- 词典：内置精简 ECDICT SQLite
- 大小写：不敏感
- 命名：支持 camelCase、PascalCase、snake_case

## 发布

需要发布到 JetBrains Marketplace。
