# Local Dictionary 状态栏组件设计

## 目标

在 IntelliJ 状态栏显示最近一次本地词典查询结果，并暴露查询错误状态。

## 组件行为

- 注册一个 `StatusBarWidget`，标识为 `LocalDictionaryStatusBarWidget`。
- 查询成功时显示最近一条结果，例如 `cache: 高速缓存`。
- 未命中时显示 `未找到`。
- 词典加载或查询异常时显示 `错误`，并在工具提示中显示异常概要。
- 点击错误状态时打开 IDE 日志目录，便于诊断。
- 组件初始状态为 `Local Dictionary`。

## 数据流

- `DictionaryHoverService` 在每次查询完成后将结果、未命中或异常通知状态栏组件。
- 状态栏组件在 IDE UI 线程更新显示。
- 编辑器悬停提示保持现有行为，不依赖状态栏组件。

## 测试

- 单元测试验证成功、未命中和错误状态的显示文本及工具提示。
- 插件结构测试验证状态栏组件扩展可加载。
